# AI Powered Personalised Mock Interview System

An AI-based personalised interview preparation platform designed to help students practise technical interview questions, prepare for job roles, and improve their interview skills.

## 📌 Project Overview

The **AI Powered Personalised Mock Interview System** is a web-based project that aims to make interview preparation easier and more accessible for students. It provides a platform where users can explore interview preparation features, access questions, and practise for technical interviews.

## 🎯 Objectives

- Provide a simple platform for technical interview preparation.
- Help students prepare for different job roles.
- Organise interview preparation questions.
- Provide a user interface for login and dashboard access.
- Explore AI-assisted question generation and interview preparation.
- Build a foundation for personalised mock interviews and performance tracking.

## ✨ Project Modules

The repository currently contains the following main pages and components:

- **Login Page (`login.html`)** – User login interface.
- **Home Page (`index.html`)** – Main entry point of the application.
- **Dashboard (`dashboard.html`)** – Dashboard interface for accessing project features.
- **AI Paper Generation (`generate-paper.html`)** – Interface related to generating interview preparation papers.
- **AI-Based Paper (`paper-by-ai.html`)** – Page related to AI-assisted paper generation.
- **Backend (`server.js`)** – Node.js server file.
- **CSS (`css/`)** – Stylesheets for the user interface.
- **JavaScript (`js/`)** – Client-side scripts for interactive functionality.

*Note: The listed files represent the current project structure. The actual functionality of each module depends on its implementation in the source code.*

## 🛠️ Technology Stack

## ⚙️ Installation and Setup

### Prerequisites

Install the following software before running the project:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- Visual Studio Code or another code editor
- A modern web browser

### Steps to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Dhruv-Rathor/Ai_Powered_Mock_Interview_System.git
   ```

2. Open the project folder:

   ```bash
   cd Ai_Powered_Mock_Interview_System
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the server using the command configured in `package.json`, or run:

   ```bash
   node server.js
   ```

5. Open the local URL displayed by the server in your browser. If the project uses a different port or requires environment variables, follow the configuration in `server.js`.

## 🚀 Planned Features

The following features are part of the project's intended development scope:

- Job-role-based interview preparation.
- Searchable technical interview questions.
- Topic and difficulty-based question filtering.
- Level-based mock interviews.
- AI-based answer evaluation and feedback.
- Interview history and performance tracking.
- Identification of strong and weak areas.
- Personalised improvement suggestions.
- Database integration using MongoDB.
- An administrative interface for managing questions and related data.

These features will be implemented progressively as the project develops.

## 🗓️ Development Plan

The project is planned to be developed in phases:

1. **Phase 1 – Requirement Analysis and Initial Prototype:** Identify project requirements, design the system architecture and database, and prepare the basic interface.
2. **Phase 2 – Core Functionality:** Develop and connect the main application modules.
3. **Phase 3 – AI and Database Integration:** Integrate the required AI service and persistent data storage.
4. **Phase 4 – Testing and Improvements:** Test the application, fix bugs, and improve usability.
